# PClonline 隐私政策

最近更新：2026-10-13

PClonline（下称"本启动器"）是基于 PCL2-CE 的开源 Minecraft 启动器，提供玩家自建的 P2P 联机功能。本政策说明我们收集什么、为什么收集、存在哪里、以及你有什么权利。

本启动器由个人开发者维护，服务器部署在中国境内。**我们不出售用户数据，也不投放任何广告。**

---

## 一、我们收集的信息

### 1. 账号信息
- **电子邮箱**：作为账号唯一标识。
- **昵称**：最多 7 个字，**仅用于好友列表显示**，不参与任何查找，不要求唯一。
- **密码**：服务器**不保存明文**。密码使用 scrypt（n=2^14, r=8, p=1）配合每个账号独立的随机盐值进行单向哈希后存储，任何人都无法从数据库还原你的密码。
- **密码在网络上的传输方式**：自 **v50.12.0** 起，注册、登录、好友与联机信令全部经 **TLS 加密**后送达我们的服务器（证书为我方自签根签发、地址锁定到服务器 IP，客户端只信任这一张根，不依赖系统信任库）。**使用更早版本的你，登录口令仍以未加密的 HTTP 明文传输**，同一网络内的他人（如公共 Wi-Fi 热点）有可能截获；请尽快更新。老版本无法直接切断，因为它的地址已随包分发，我们会持续引导更新。

### 2. 登录会话
- 登录成功后服务器发放一个随机会话令牌；数据库里只保存该令牌的 SHA-256 哈希，有效期 30 天。
- 新设备登录会使该账号的旧会话失效（单设备在线）。
- 令牌在你本机以 Windows 数据保护 API（DPAPI，当前用户范围）加密保存，不与其他 Windows 用户共享。

### 3. 设备识别码（防批量注册）
- 注册时，本启动器会在本机采集若干硬件标识（SMBIOS 主机 UUID、主板型号与序列号、处理器 ID，取不到时回退到系统安装标识），在**本机**汇总计算为一个不可逆摘要后上报。
- **服务器不保存这些硬件标识的原值，也不保存上报的摘要本身**，只保存该摘要经服务器端密钥二次混淆（HMAC-SHA256）后的结果。即使数据库整份泄露，也无法还原出任何硬件信息，也无法反向匹配你的设备。
- 用途仅限于限制"同一台设备批量注册账号"。**登录不受设备限制**：换电脑、重装系统、在网吧或宿舍使用他人电脑登录，都不会被拒绝。
- 若本机硬件标识采集不完整，本启动器会放弃这一判定并正常放行注册，不会因此把你挡在门外。

### 4. 联机运行数据
为维持 P2P 直连功能并排查故障，服务器会记录：
- 你的 **IP 地址**（用于接口限流与防滥用，以及回显连接地址）；
- **打洞诊断指标**：NAT 类型、候选端口、连接成功或失败、房间码、客户端版本号。这些用于统计"对称 NAT 下的直连成功率"以改进连接质量，不包含游戏内容或聊天内容。
- **房间信息**：房间码、房主、成员列表、Minecraft 服务器地址与公告（MOTD）。

### 5. 自动更新
检查更新时会**先访问我们的服务器**，取一份约 16 KB 的更新清单；只有取不到时才回落 GitHub。
更新包本体固定从 GitHub Releases 下载，不经过我们的服务器。因此：

- 我们的服务器会看到你的 **IP 地址、所请求的清单与访问时间**；
- 回落到 GitHub 时，GitHub 会看到你的 IP 地址与所下载的客户端版本。

这份清单带 ECDSA 签名，服务器被攻破也无法替换成伪造版本。我们不会用这次访问做投放、统计或画像。

### 6. 服务器访问日志
我们的服务器会为每个 API 请求写一行访问日志，内容包含**来源 IP 地址、请求路径与响应状态码**，
保存在服务器的系统日志中，仅用于限流排障与滥用追查；按系统默认保留策略存放（最长约三个月），不做二次利用。

## 二、其他玩家能看到什么（请务必读完）

**在同一房间内，其他玩家可以看到你用于登录的邮箱账号、昵称与在线状态。** 这是 P2P 联机建立连接关系的必要信息，无法在不提供该信息的情况下与你连接。

> ⚠ 因此请**不要使用你的主力私人邮箱**注册。建议专门注册一个仅用于联机的邮箱地址。

好友关系仅在你主动添加对方后建立；添加对方需要知道对方的邮箱账号。

## 三、我们不做什么

- **不接入任何第三方统计、广告或崩溃上报服务。** 上游 PCL2-CE 的遥测（Sentry）能力在本 fork 中已整体停用，异常只写入你本机的日志文件，不会上传。
- 不读取、不上传你的 Minecraft 游戏文件、存档、聊天内容或账号密码（游戏账号登录凭据仅用于向微软/Mojang 官方接口验证，不存储于我们的服务器）。
- 不收集通讯录、位置、麦克风、摄像头权限。
- 不向任何第三方出售、共享或提供你的个人信息（打洞直连过程中你的 IP 会直接暴露给同房间的其他玩家，这是 P2P 技术的固有特性，不属于"向第三方提供"）。

## 四、数据保留与删除

- 账号、会话、好友、设备绑定与房间数据保存在我们自有的位于中国境内的服务器上。
- **你可以自助删除全部数据**：在启动器「联机 → 账号」中登录原账号并执行注销（需输入密码确认）。注销会立即清除该账号的用户记录、全部登录会话、好友关系、设备绑定记录，以及该账号名下正在运行的房间。此操作不可撤销。
- 会话令牌默认 30 天后自动过期；打洞诊断指标按时间滚动清理。

## 五、未成年人

本启动器面向 Minecraft 玩家，其中可能包含未成年人。若你是未成年人，请在监护人陪同下阅读本政策并在监护人同意后使用。我们不会主动收集未成年人的身份信息；监护人如发现相关情况，可通过下方联系方式要求删除账号。
