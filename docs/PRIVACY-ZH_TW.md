# PClonline 隱私政策

最近更新：2026-10-13

PClonline（下稱「本啟動器」）是基於 PCL2-CE 的開源 Minecraft 啟動器，提供玩家自建之 P2P 聯機功能。本政策說明我們收集什麼、為何收集、存放於何處，以及你享有何種權利。

本啟動器由個人開發者維護，伺服器部署於中國境內。**我們不出售使用者資料，亦不投放任何廣告。**

---

## 一、我們收集的資訊

### 帳號資訊
- **電子郵件地址**：作為帳號唯一識別碼。
- **暱稱**：最多 7 個字，**僅用於好友清單顯示**，不参与任何查詢比對，不要求唯一。
- **密碼**：伺服器**不儲存明文**。密碼以 scrypt（n=2^14, r=8, p=1）搭配每個帳號獨立之隨機鹽值進行不可逆雜湊後儲存，任何人（含維護者）均無法由資料庫還原你的密碼。
- **密碼在網路上的傳輸方式**：自 **v50.12.0** 起，註冊、登入、好友與聯機信令一律經 **TLS 加密**後送達我們的伺服器（憑證由我方自簽根簽發、位址鎖定至伺服器 IP，用戶端只信任此一根憑證，不依賴系統信任庫）。**使用更早版本的你，登入口令仍以未加密的 HTTP 明文傳輸**，同一網路內的他人（如公共 Wi-Fi 熱點）有機會擷取；請儘速更新。

### 登入工作階段
- 登入成功後發放隨機工作階段權杖；資料庫僅儲存該權杖之 SHA-256 雜湊，有效期限 30 天。
- 新裝置登入會使該帳號舊工作階段失效（單一裝置在線）。
- 權杖在本機以 Windows 資料保護 API（DPAPI，目前使用者範圍）加密儲存。

### 裝置識別碼（防批次註冊）
- 註冊時，本啟動器會在本機收集數項硬體識別碼（SMBIOS 主機 UUID、主機板型號與序號、處理器 ID；無法取得時改使用系統安裝識別碼），並在**本機**彙整為不可逆摘要後上報。
- **伺服器不儲存上述硬體識別碼原值，也不儲存該摘要本身**，僅儲存摘要經伺服器端金鑰二次混淆（HMAC-SHA256）後的結果。即使資料庫整份外洩，也無法還原任何硬體資訊，無法反向比對你的裝置。
- 用途僅限於限制「同一台裝置批次註冊帳號」。**登入不受裝置限制**：換電腦、重裝系統、在網咖或宿舍使用他人電腦登入，均不會被拒絕。
- 若本機硬體識別碼無法可靠取得，本啟動器會放棄該判定並正常放行註冊，絕不會因收集失敗而把你擋在門外。

### 聯機運作資料
為維持 P2P 直連功能並排除故障，伺服器會記錄：
- 你的 **IP 位址**（介面限流與防濫用、連線位址回顯）；
- **打洞診斷指標**：NAT 類型、候選埠、連線成功或失敗、房間碼、用戶端版本。不含遊戲內容與聊天內容。
- **房間資訊**：房間碼、房主、成員清單、Minecraft 伺服器位址與公告（MOTD）。

### 自動更新
檢查更新時會**先存取我們的伺服器**，取一份約 16 KB 的更新清單；只有取不到時才回落 GitHub。
更新套件本體固定自 GitHub Releases 下載，不經過我們的伺服器。因此：

- 我們的伺服器會看到你的 **IP 位址、所請求的清單與存取時間**；
- 回落至 GitHub 時，GitHub 會看到你的 IP 位址與所下載的用戶端版本。

這份清單帶 ECDSA 簽章，伺服器被攻破也無法替換成偽造版本。我們不會用這次存取做投放、統計或畫像。

### 伺服器存取日誌
我們的伺服器會為每個 API 請求寫一行存取日誌，內容包含**來源 IP 位址、請求路徑與回應狀態碼**，
儲存在伺服器的系統日誌中，僅用於限流排障與濫用追查；依系統預設保留策略存放（最長約三個月），不做二次利用。

## 二、其他玩家能看到什麼（請務必读完）

**在同一個房間內，其他玩家可以看到你用登入的電子郵件帳號、暱稱與在線狀態。** 這是建立 P2P 連線關係的必要資訊，無法在不提供的情況下與你連線。

> ⚠ 因此請**不要使用你的主力私人信箱**註冊。建議專門註冊一個僅供聯機使用的信箱地址。

好友關係僅在你主動新增對方後建立；新增對方需要知道對方的信箱帳號。

## 三、我們不做的事

- **不接入任何第三方統計、廣告或當機上報服務。** 上游 PCL2-CE 的遙測（Sentry）能力在本 fork 中已整體停用，異常僅寫入你本機的記錄檔，不會上傳。
- 不讀取、不上傳你的 Minecraft 遊戲檔案、存檔、聊天內容或遊戲帳號密碼（遊戲登入憑證僅用於向 Microsoft / Mojang 官方介面驗證，不儲存於我們的伺服器）。
- 不收集通讯录、位置、麥克風、攝影機權限。
- 不向任何第三方出售、共享或提供你的個人資訊。（P2P 打洞過程中你的 IP 會直接暴露給同房間的其他玩家，此為該技術的固有特性，不屬於「提供給第三方服務」。）

## 四、資料保留與刪除

- 帳號、工作階段、好友、裝置綁定與房間資料儲存於我們自有、位於中國境內的伺服器。
- **你可以自行刪除全部資料**：在啟動器「聯機 → 帳號」中登入原帳號並執行注销（需輸入密碼確認）。注销會立即清除該帳號的使用者記錄、全部工作階段、好友關係、裝置綁定記錄，以及該帳號名下正在執行的房間。此操作不可回復。
- 工作階段權杖預設 30 天後自動逾期；打洞診斷指標按時間滾動清理。

## 五、未成年人

本啟動器的使用者可能包含未成年人。若你為未成年人，請在監護人陪同下閱讀本政策並經其同意後使用。我們不會主動收集未成年人的身分資訊；監護人可透過下方聯絡方式要求刪除帳號。
